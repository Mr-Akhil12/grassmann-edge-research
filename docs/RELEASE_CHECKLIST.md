# Before any public release

- [ ] Project uses correct author/owner and approved license.
- [ ] All references, sources, third-party licenses documented.
- [ ] README distinguishes tested findings from hypotheses.
- [ ] Causality math and indexing independently reviewed.
- [ ] Code tested on fresh machine / GitHub Actions.
- [ ] All seeds, preprocessing, split hashes and environments captured.
- [ ] All failures, null and adverse results retained.
- [ ] No access tokens, device serials, private paths, email, proprietary data.
- [ ] No private machine inventory included in Git history.
- [ ] No source weights/large generated artifacts committed inadvertently.
- [ ] Android tests use explicit permission, no root.
- [ ] Measurement methodology supports each published claim.
- [ ] Public repo approved separately from local research staging.
